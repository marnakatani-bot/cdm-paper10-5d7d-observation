# データ公開・保全方針（ドラフト）

1. **公開してよい候補**：入力内容を含まない `index.html`、空欄の事例票、比較手順書の草案・著者確定版、版変更記録、公開に承認した研究素材。
2. **非公開**：研究ノートの完全JSONバックアップ、未公開の逐語記録、個人情報、非公開対話、未公表の着想、公開承認前の予想メモ、認証トークン。
3. **アプリの性質**：`index.html` の初期データには観測の個別記録を含めない。入力は同じブラウザの `localStorage` に保存され、ブラウザ・端末を替えても同期されない。公開リポジトリにHTMLコードを置くだけでは、使用者の入力済みデータは共有されない。
4. **JSONバックアップ**：HTMLから書き出す全量JSONは機密情報を含みうる。公開リポジトリのコミットへ追加しない。安全な私的保存先へ複数バックアップする。
5. **比較前の公的記録**：著者が手順を確定したとき、対応づけの結果を確認する前の確定版を公開する。固定日時、判定規則、変更理由、既に知っていた観測・予想の範囲を明記する。
6. **変更履歴**：公開後の変更は確定版を上書きして消さず、新しい版として残す。原文・回顧・AI整理の出どころを混ぜない。
7. **証拠の意味**：GitHubは記録がその時点で公開されていたことや公開後の改訂履歴をたどる補助になる。公開は観測の正しさ、理論の実証、著作権・先取権の確定を保証するものではない。
8. **長期保存**：固定版が確定したら、公開GitHubリポジトリをZenodoと連携し、release時点の資料をDOI付きでアーカイブする案を検討する。公開・Zenodo登録は著者の承認後に行う。
9. **認証情報**：GitHub用のトークンやパスワードをHTMLへ埋め込まない。GitHubとの連携操作は権限管理されたGitHubアプリや本人が承認したGitHub画面から行う。
10. **GitHub Pages**：インターネット公開のWebサイトとして動作する。日記や非公開原文を含むデータの入力は、原則として手元のオフラインHTMLで行い、サーバー公開版と使い分ける。公開版は第三者にもアクセス可能。
